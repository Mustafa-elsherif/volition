What is true about the model

Every number here comes from trials the model never trained on, averaged over three seeds. The strong within-session baselines are shown next to the shared model, not hidden behind it.

One model across sessions

The shared neuron-set transformer decodes choice well above chance across ten mice with a single set of weights, and its probabilities are well calibrated.

The cost of sharing

Linear and forest decoders retrained for one animal are more accurate. Reading a variable, shared neuron set across animals trades accuracy for one deployable, interpretable model.

A new animal is near chance

Predicting a mouse the model never saw, from shared regions alone, stays close to chance for every method tested. Pre-movement choice signals here do not transfer across animals.

Graceful under loss

Because the model reads a set, neurons can be dropped at decode time. Accuracy falls gradually as a growing fraction is removed.
